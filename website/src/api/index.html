Image → Schematic / API

Generate schematics using PNG-to-NBT's engine.

TS interface | JS module

Quick-start

import { connect } from "https://evmodder.net/PNG-to-NBT/api.js";

const generator = await connect();
try {
  const result = await generator.generateTile({
    colors: new Uint8Array(128 * 128).fill(7 * 4 + 1),
    blocks: { 7: "bamboo_block[axis=x]" },
    options: { mode: "suppress_step_checker" },
  });
  // files: { name, data: Uint8Array }[], each a gzip-compressed structure NBT.
  console.log(result.files, result.warnings, result.effectiveOptions);
}
finally { generator.dispose(); }

You can reuse one connection; calls queue in order. Inputs are copied on submission. dispose() stops active work and rejects queued calls.

Contract

  • colors: 16384 map-color bytes, indexed by z * 128 + x, north at top. Shade 3 is unsupported.
  • blocks: map each used nontransparent base color ID to a block, e.g. { 11: "minecraft:stone" }.
  • options: defaults apply when omitted, but non-flat tiles require an explicit, compatible options.mode.

Options

Non-flat tiles require a compatible mode. Resolved options are returned in effectiveOptions. Unknown fields or invalid values are rejected. CrubTech options are volatile: they follow the current CrubTech platform and may change or lose support when it is revised.

Integration

  • Exports: result.files contains one or more named NBT files.
  • Connection: reuse it across tiles; calls queue in order. dispose() stops pending work and releases the worker.
  • Errors: generation failures reject with a message and code; invalid input uses INVALID_INPUT.
  • Warnings: result.warnings lists { code, message } entries. Codes are stable; messages are English and may be reworded.
    CRUBTECH_CONSTRAINTS, KEEP_EXTRAS, LIFT_INACTIVE, LIFT_UNSUPPORTED, NORTH_SOUTH_STEPS, NORTH_SOUTH_TWO_LAYER, VOID_FILLERS, WATER_SUPPORT, WORLD_MIN_Y;
    PLACEMENT_ATTACHMENT_SUPPORT, PLACEMENT_AUTO_SUPPORT, PLACEMENT_CORAL_SUPPORT, PLACEMENT_CROP_LIGHT, PLACEMENT_FALLING, PLACEMENT_FIRE_SPREAD, PLACEMENT_FROSTED_ICE, PLACEMENT_GRASS_SPREAD, PLACEMENT_GROWTH_COVER, PLACEMENT_ICE_MELT, PLACEMENT_ICE_SNOW_MELT, PLACEMENT_ICE_SNOW_RISK, PLACEMENT_INVALID_SUPPORT, PLACEMENT_MELT_RISK, PLACEMENT_MISSING_COVER, PLACEMENT_MISSING_SUPPORT, PLACEMENT_MUSHROOM_LIGHT, PLACEMENT_MUSHROOM_SPREAD, PLACEMENT_SCAFFOLD_CONNECTION, PLACEMENT_SCAFFOLD_SUPPORT_FILLER, PLACEMENT_SHELF_SUPPORT, PLACEMENT_SNOW_MELT, PLACEMENT_SNOW_RISK, PLACEMENT_SUPPORT_BLOCK, PLACEMENT_SUPPORT_MODE, PLACEMENT_TNT, PLACEMENT_TNT_IGNITION, PLACEMENT_TRANSPARENT_SUPPORT
  • Hosting: HTTP(S) caller; no opaque sandbox. Import URL directly; keep external in bundlers. CSP: allow API origin in script-src and frame-src.
  • Versions: protocolVersion identifies the interface; engineRevision, the generator build. Include the revision and effective options in bug reports.
